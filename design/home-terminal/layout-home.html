정한 것

  • 화면 전체가 터미널이에요. 맨 위에 사이트 이름 Daljin's Home, 그 아래가 명령을 치는 터미널이고, 터치 기기에서는 맨 아래에 명령 버튼 줄이 붙어요(2026-11-17 사용자 결정).
  • 처음 들어오면 환영 문구 두 줄 다음에 ls 를 한 번 실행한 결과를 보여 줘요. 명령을 몰라도 첫 화면에서 앱을 고를 수 있어요.
  • 명령은 help, ls, open <앱>, clear 네 개예요. 앱 이름만 쳐도 그 앱이 열리고, 대소문자는 가리지 않아요. 프롬프트는 guest@daljin:~$ 예요.
  • ls 와 help 결과는 누를 수 있어요. 누르면 그 명령을 친 것처럼 터미널에 남고 실행돼요. help 의 open <앱> 을 누르면 입력칸에 open 을 채워 줘요.
  • 명령은 직접 치고 눌러서도 실행해요(2026-11-17 사용자 결정). 터치 기기(pointer: coarse)에서는 아래에 help, ls, 앱 이름들, clear 버튼 줄을 두고, 버튼을 눌러도 키보드를 올리지 않아요. 마우스 기기에서는 이 줄을 숨기고, 터미널 아무 곳을 눌러도 입력칸으로 가요.
  • 이 사이트 안의 앱(Daltris)은 터미널 위에 창으로 열려요. 태블릿과 PC 에서는 최대 480x640 창을 가운데에 두고, 모바일에서는 화면을 꽉 채워요. 뒤 터미널은 막으로 어둡게 덮고 누를 수 없게 해요.
  • 다른 사이트 앱(이력서, 깃허브)은 창 없이 바로 새 탭에서 열고, 터미널에 새 탭에서 열었다는 줄과 주소 링크를 남겨요(2026-11-17 사용자 결정). 두 사이트 모두 다른 사이트의 창 안에 들어가는 것을 막아 두어서 창으로는 열 수 없어요.
  • 창은 Esc, 닫기 버튼, 창 뒤 막을 눌러 닫아요. 닫으면 포커스가 입력칸으로 돌아와요. 창 제목이 길면 한 줄에서 말줄임하고, 마우스를 올리면 전체 이름이 보여요.
  • 커서는 글자 한 칸 크기의 네모예요. 1초 주기로 깜빡이고, 입력칸에서 포커스가 빠지면 속이 빈 네모가 돼요. 글자를 골라 두면 고른 글자를 커서 색으로 칠해요.
  • 오류 줄은 색과 함께 앞에 ! 를 붙여 색만으로 구분하지 않아요. 상태 표시는 신규 +, 베타 β, 오류 ! 이고, 다른 사이트로 가는 앱에는 새 탭 표시를 붙여요.
  • 아이콘은 16x16 칸에 픽셀을 한 칸씩 직접 찍고, 아이콘 하나에 색을 세 개까지만 써요(2026-11-17 사용자 결정). 필터는 쓰지 않아요. ls 에서는 두 배인 32px, 창 제목줄에서는 원래 크기인 16px 로 보여 줘요. 아이콘이 없는 앱은 빈 창 아이콘을 써요.
  • Daltris 는 사이트 안 앱 창을 보여 주는 예시로만 시안에 남겨요. 실제 사이트에는 일단 넣지 않아요(2026-11-17 사용자 결정).
  • 입력칸 글자는 16px 이라 iOS 에서 입력할 때 화면이 확대되지 않아요. 자동 대문자, 자동 고침, 맞춤법 검사는 꺼요.
  • 구현 메모: 앱 목록은 HTML 에 링크 목록으로 두어 스크립트가 꺼져도 앱으로 갈 수 있게 해요. 사이트 안의 앱 창은 같은 사이트의 apps/<이름>/ 을 iframe 으로 열고, 열 때 포커스를 iframe 으로 옮겨요. 화면 높이는 100dvh 이고, 출력 영역은 role=log 로 스크린리더에 읽혀요.

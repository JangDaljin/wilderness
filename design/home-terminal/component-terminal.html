터미널 줄

터미널에 쌓이는 줄과 입력 줄, ls 한 줄, 명령 버튼, 아이콘이에요.

화면터미널 줄앱 창

줄

친 명령은 프롬프트와 함께 남아요. 오류 줄은 앞에 ! 가 붙어요. Tab 후보가 여럿이면 후보를 한 줄로 보여 줘요.

Type=Welcome
Type=Command
Type=Output
Type=Error
Type=External
Type=Candidates
Type=Cancel
Type=Empty

입력 줄

커서는 글자 한 칸 크기 네모예요. 글자 위에 있으면 그 글자를 바탕색으로 뒤집어 보여 줘요.

State=Focus
State=Typing
State=CaretInside
State=Selection
State=Blur

ls 한 줄

줄 전체가 버튼이에요. 앱 이름이 명령 이름과 같으면(Daltris) 한 번만 보여 줘요.

State=Default
State=Hover
State=Pressed
State=Focus
Type=External
Status=Beta
Status=Error

help 결과

Type=Help

명령 버튼

터치 기기에서만 화면 아래 줄에 나와요. 높이는 48px 이에요.

State=Default
State=Hover
State=Pressed
State=Focus

아이콘

16x16 칸에 직접 찍은 픽셀이에요. 이력서는 접은 종이, 깃허브는 갈라졌다 만나는 가지, Daltris 는 빈칸으로 떨어지는 블록이에요. 크기는 16의 배수로만 키워요.

Icon=Note 16
Icon=Note 32
Icon=Note 64
Icon=Branch 16
Icon=Branch 32
Icon=Branch 64
Icon=Blocks 16
Icon=Blocks 32
Icon=Blocks 64
Icon=Fallback 32

최악의 데이터

주소처럼 끊기지 않는 글은 아무 곳에서나 줄을 바꿔요. 입력 줄은 한 줄을 지키고 커서가 보이도록 옆으로 밀려요. 설명이 없으면 둘째 줄을 통째로 빼요.

State=WorstCase 끊기지 않는 주소
State=WorstCase 한글 명령
State=WorstCase 긴 입력
State=WorstCase 한글 입력
State=WorstCase 긴 이름과 긴 설명
State=WorstCase 한 글자, 설명 없음, 아이콘 없음
State=WorstCase 이모지
State=WorstCase 긴 주소의 다른 사이트 앱
